# Third-party data attribution

## OpenSubtitles2018 word-form frequency data

G-switcher 1.0.10 includes a generated, filtered frequency table derived from the Russian and English word-form frequency lists in `kapzam123/subtitle-frequency`, pinned to commit `b5ff7d0d26df0863b9b6c5e8f946961ea9fef1f3`. That repository mirrors data derived from OpenSubtitles2018.

Original data license: Creative Commons Attribution 3.0 (CC BY 3.0). Source repository: https://github.com/kapzam123/subtitle-frequency . Original project attribution: OpenSubtitles / OpenSubtitles2018.

G-switcher stores only normalized word forms and source ranks needed for local detector decisions. No subtitle text, sentences, raw counts, or network retrieval code is linked into the runtime executable. The generator is a development-time reproducibility tool only.
