# Проверка XML-замены в установленном Word

Это отдельная диагностика для второго этапа ремонта G-switcher. Она не устанавливает и не обновляет программу.

1. Закройте Word и G-switcher.
2. Распакуйте весь архив в обычную папку.
3. Дважды щёлкните `Run-WordXmlProbe.cmd`.
4. Дождитесь сообщения о результате (не более двух минут). Пришлите папку нового запуска из `results`, упакованную в ZIP.

Диагностика создаёт собственный скрытый несохранённый документ со словом `ghbdtn` и разным оформлением букв. Она получает настоящий `Range.WordOpenXML`, заменяет только текстовые узлы основного документа на `привет` и сохраняет все остальные части пакета. Затем проверяет одну вставку `InsertXML`, обычную отмену Word и восстановление сохранённого исходного XML. Рабочие документы не открываются. При уже запущенном Word диагностика откажется работать.

Отчёт содержит версию Word, этап остановки, хеши XML, время вставок, сравнение текста с конечным знаком абзаца и 13 свойств для каждой из шести букв: Name, Size, Bold, Italic, Underline, Color, StrikeThrough, Subscript, Superscript, SmallCaps, AllCaps, HighlightColorIndex, LanguageID. Все результаты относятся к созданному тестовому документу. Исходный экспорт сохраняется и при отказе преобразования; его нельзя обрезать или удалять из него зависимости для принудительного допуска.

Результат `MEASURED_CHECKS_PASSED` означает успешность перечисленных измерений. Он не доказывает сохранение всех эффективных свойств, поведение в произвольном документе, отсутствие зависания при вводе, атомарность COM, положение курсора или готовность XML-модуля продукта. Диагностическое преобразование имеет более широкий формат пакета, чем прежний Rust-прототип; его успех не разрешает подключать прототип к записи в Word.

При `UNKNOWN_TIMEOUT` останавливается только дочерний процесс диагностики. Word автоматически не завершается; тестовый экземпляр может остаться открытым. Не запускайте диагностику повторно, сначала сохраните отчёт и закройте оставшийся тестовый Word. Ничего не сохраняйте поверх рабочих документов.

Файлы остаются локально, сетевых обращений у диагностики нет. XML содержит сгенерированный тестовый текст и полный служебный пакет Word; в нём могут присутствовать метаданные установки. Не публикуйте папку результатов в открытом репозитории. Проверенный EXE G-switcher и его ручная приёмка остаются отдельными шагами.

Точный существующий кандидат: `830abfe7ef99a7c6e8ca8291fc7ae802ac5edd78`. Версия CDC сохранена: 2.12.1.

Первичная документация: [WordOpenXML](https://learn.microsoft.com/en-us/office/vba/api/word.range.wordopenxml), [InsertXML](https://learn.microsoft.com/en-us/office/vba/api/word.range.insertxml), [UndoRecord](https://learn.microsoft.com/en-us/office/vba/word/concepts/working-with-word/working-with-the-undorecord-object).
