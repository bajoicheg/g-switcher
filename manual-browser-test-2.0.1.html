G-switcher 2.0.1 — тест браузера

Локальная страница для ручной проверки Microsoft Edge и Google Chrome. Она не загружает внешние ресурсы, не отправляет данные и не использует сеть.

Не вводите реальные пароли, PIN, OTP, ключи API или другие секреты. Поле пароля ниже предназначено только для вымышленных тестовых данных.

1. Auto

Установите английскую раскладку и напечатайте ghbdtn, затем пробел. Ожидается привет . Текст до и после слова не должен повреждаться.

2. Manual current word + Undo

В режиме Manual-only напечатайте ghbdtn, примените hotkey текущего слова, затем Undo. Ожидается точное восстановление исходного текста и раскладки.

3. Selected text + Undo

Выделите только ghbdtn rfr ltkf, выполните преобразование выделения и затем Undo. Ничего за пределами выделения меняться не должно.

4–5. Caret race и focus race

Создайте ситуацию перед границей слова, затем переместите каретку мышью/стрелками или быстро смените поле. Устаревшая коррекция не должна примениться ни к старому, ни к новому полю.

6. Password / sensitive field

Используйте только вымышленную строку, например ghbdtn123. G-switcher не должен изменять содержимое или переключать раскладку из-за своих действий в этом поле.

7–8. Pause / modes / fail-open

На полях выше проверьте Pause/Resume, Auto, Manual-only и Disabled. Если конкретный контрол не поддерживается, исходный ввод и hotkey приложения должны остаться недеструктивными — это фиксируется как UNSUPPORTED/FAIL-OPEN, а не как «не тестировалось».

Страница является статическим локальным артефактом релизного test kit. JavaScript отсутствует.
